# Security Policy

## Supported Versions

Security fixes are prioritized for the current main development line and the latest released commercial and community builds where applicable.

## Reporting a Vulnerability

If you believe you have found a security issue in QuantOS, please report it privately instead of opening a public issue.

Send reports to: security@quantos.dev

Please include:

- A clear description of the issue
- The affected version or commit, if known
- Steps to reproduce
- Any relevant logs, screenshots, or proof of concept material

## What to Expect

- We will acknowledge receipt as soon as practical.
- We will investigate and triage the report.
- If the issue is confirmed, we will coordinate a fix and disclosure plan.

## Safe Reporting

Do not attempt exploitation beyond what is necessary to demonstrate the issue, and do not access or disclose data that does not belong to you.

## Public Disclosure

Please wait for the project maintainers to coordinate public disclosure before sharing details of an unpatched vulnerability.
