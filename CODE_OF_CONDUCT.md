# Code of Conduct

QuantOS aims to be a respectful, inclusive project.

## Expected Behavior

- Be constructive and professional.
- Give feedback on the work, not the person.
- Keep discussions focused on the project.
- Respect different backgrounds, experience levels, and viewpoints.

## Unacceptable Behavior

- Harassment, discrimination, or intimidation
- Personal attacks or abusive language
- Deliberate disruption of discussions or reviews
- Sharing private information without permission

## Enforcement

Project maintainers may remove comments, decline contributions, or restrict participation when behavior violates this code of conduct.

## Reporting

If you need to report a problem, contact the project maintainers at conduct@quantos.dev.

## Scope

This code of conduct applies to project discussions, issues, pull requests, and any official community spaces associated with QuantOS.
